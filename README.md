# Money in Motion

Your money. Moving forward.

A standalone South African investment website prototype with a guided questionnaire, automatic fund matching, savings and retirement planning calculators, editable growth charts, fee comparisons and an application preview.

## Run locally

Install Node.js 22 or later, then run:

```sh
node server.cjs
```

Open the local URL printed by the server. Website source files are in `dist/`; no build step is required. A static host can serve that directory directly.

## Preview status

This is a demonstration. It does not open investment accounts, submit applications, process payments or store client information. Fund performance and fee information are dated snapshots. Growth figures are editable illustrations, not guaranteed returns.

The repository contains the website assets and local preview server. Internal project notes and local test infrastructure are excluded.
